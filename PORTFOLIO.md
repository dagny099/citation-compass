# Academic Citation Platform - Portfolio Summary

**AI-Powered Scholarly Matchmaking System**  
*Connecting academic research through graph neural networks*

> This is a personal portfolio project built and maintained by a single author ([dagny099](https://github.com/dagny099)). "We/our" below refers to the project, not a team.

---

## Executive Overview

This project demonstrates **end-to-end data science expertise** through a complete academic citation prediction system. Using a TransE knowledge-graph embedding model on a 12,595-paper citation network, the system learns semantic relationships between papers and predicts likely missing citations.

**Key Achievement**: Implemented "scholarly matchmaking" - using a learned embedding model to surface candidate connections in academic literature.

## Key Results

### Model & Training (verifiable from `models/training_metadata.json`)
- **12,595 papers / 18,912 citations** in the training graph
- **1,612,288 parameters**, 128-dimensional entity embeddings
- **Early convergence** after 26 epochs, with a **98.7% reduction in training loss**
- **18.5 MB** trained model checkpoint (`models/transe_citation_model.pt`)

> **On ranking accuracy (MRR / Hits@K / AUC):** the evaluation harness is wired
> into the pipeline, but this repo does not yet ship a saved, reproducible
> evaluation run — the metrics shown in the app's pipeline page are currently
> **simulated for demonstration**. Rather than quote unverified numbers, they are
> omitted here. Real metrics can be generated by evaluating the trained model on
> `models/test_data.pkl` and committing the results.

### Capabilities
- **Ranked citation recommendations** for any paper in the graph, with confidence scores
- **Interactive exploration** through a web-based visualization dashboard
- **Service-oriented architecture** with Docker / Cloud Run deployment support
